# 基金日报

Windows 桌面基金看板：实时行情、持仓盈亏、红黑榜、涨跌柱状图、已清仓灰章、交易记录与收益日历、一键导出 Excel。行情取自公募基金接口；**全部持仓与交易数据仅存本地磁盘，不上传**。

## 功能

- 🏠 首页看板：每只基金卡片显示净值/今日涨跌/累计盈亏，一键刷新
- 🧮 总持仓市值、今日盈亏合计（已清仓基金自动剔除）
- 🔥 今日红榜/黑榜 + 涨跌柱状图
- 💼 管理持仓：份额/每份成本录入，自动识别"本金当成本"并换算，支持粘贴导入
- 📒 交易记录：手动记一笔买入/卖出，自动换算金额与份额
- 📅 收益明细：日历视图 + 月度/年度收益汇总
- 📥 导出 Excel：持仓、交易流水、收益明细、行情快照，勾选后一键导出为一个 Excel（每类数据一个 sheet）
- 🚫 已清仓灰章：卖掉的基金盖灰章，不再计入合计与榜单，卡片仅观察；可随时恢复，状态存 `基金显示.json`

## 运行

源码运行（Python 3.10+）：

```
pip install -r requirements.txt
python app.py

```

到 Releases 下载 zip，解压到同一文件夹，双击 exe 运行，详见 `使用说明.txt`。首次运行，在首页「➕ 快速添加」加入第一只基金，会在 exe 同目录自动创建 `自定义基金.json`（看板名单）。

## 本地文件说明（均不入库）

| 文件 | 用途 |
|---|---|
| `自定义基金.json` | 看板名单 |
| `我的持仓.json` | 持仓账本（份额/成本） |
| `trades.json` | 交易流水（买入/卖出记录） |
| `基金显示.json` | 已清仓等显示层状态，缺席=默认 |
| `基金日报导出_*.xlsx` | 你导出的 Excel（默认存 exe 同目录，内含你的数据） |
