# 基金日报

Windows 桌面基金看板：实时行情、持仓盈亏、红黑榜、涨跌柱状图、已清仓灰章、支付宝快照对照。
行情取自公募基金接口；**全部持仓数据仅存本地磁盘，不上传**。

## 功能

- 🏠 首页看板：每只基金卡片显示净值/今日涨跌/累计盈亏，一键刷新
- 🧮 总持仓市值、今日盈亏合计（已清仓基金自动剔除）
- 🔥 今日红榜/黑榜 + 涨跌柱状图
- 💼 管理持仓：份额/每份成本录入，自动识别"本金当成本"并换算，支持粘贴导入
- 🚫 已清仓灰章：卖掉的基金盖灰章，不再计入合计与榜单，卡片仅观察；可随时恢复，状态存 基金显示.json
- 📷 OCR 快照对照：ocr_hold.py 识别支付宝持仓截图，与 app 自算市值并排核对（可选辅助工具）

## 运行

源码运行（Python 3.10+）：

    pip install -r requirements.txt
    python app.py

打包版（Windows）：到 Releases 下载 exe 双击运行。
首次运行会在 exe 同目录自动创建 自定义基金.json（看板名单），在首页「➕ 快速添加」加入第一只基金。
