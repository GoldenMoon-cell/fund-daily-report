Windows / macOS 双平台桌面基金看板：实时行情、持仓盈亏、红黑榜、涨跌柱状图、已清仓灰章、交易记录与收益日历、多账户管理、一键备份、一键导出 Excel。行情取自公募基金接口；**全部持仓与交易数据仅存本地磁盘，不上传**

## 功能

- 🏠 首页看板：每只基金卡片显示净值/今日涨跌/累计盈亏，一键刷新
- 🧮 总持仓市值、今日盈亏合计（已清仓基金自动剔除）
- 🔥 今日红榜/黑榜 + 涨跌柱状图
- 💼 管理持仓：份额/每份成本录入，自动识别"本金当成本"并换算，支持粘贴导入；「🔍 对账」用交易流水逐笔回放校准手填持仓（差异橙底待核对，保存才落盘）
- 📒 交易记录：手动记一笔买入/卖出/转换，自动换算金额与份额；转换按"转出+转入"两笔入账
- 📅 收益明细：日历视图 + 月度/年度收益汇总；份额按交易记录/买入日期逐日回溯，从第一笔交易开始记录，休市日与清仓后收益为 0
- 📥 导出 Excel：持仓、交易流水、收益明细、行情快照，勾选后一键导出为一个 Excel（每类数据一个 sheet）
- 📂 多账户：每个账户对应一个平台（支付宝/天天基金/招行等），持仓按账户独立核算，首页可切换“全部账户”或单个账户查看；支持账户间转移持仓
- 🗄 一键备份：把所有数据文件打包成 zip，可设置默认目录一键直达
- ℹ 关于本软件：版本信息 / GitHub 链接 / 隐私声明 / 免责声明 / 手动检查更新
- 🚫 已清仓灰章：卖掉的基金盖灰章，不再计入合计与榜单，卡片仅观察；可随时恢复，状态存 `基金显示.json`

## 运行

源码运行（Python 3.10+）：

```
pip install -r requirements.txt
python app.py

```

到 Releases 下载对应平台的 zip（Windows 版 / macOS 版），解压到同一文件夹运行，详见 `使用说明.txt`。Windows 双击 exe；macOS 首次需右键 app → 打开（未签名应用的正常拦截）。首次运行，在首页「➕ 快速添加」加入第一只基金，会在程序同目录自动创建 `自定义基金.json`（看板名单）。

> Windows 首次打开若提示“Windows 已保护你的电脑”：这是未签名的正常现象（SmartScreen），非病毒。点「更多信息」→「仍要运行」即可。
> macOS 首次打开若提示“无法验证开发者”：同样是未签名的正常现象，右键 app →「打开」即可。

## 本地文件说明（均不入库）

| 文件 | 用途 |
|---|---|
| `自定义基金.json` | 看板名单 |
| `我的持仓.json` | 持仓账本（份额/成本，按账户分组） |
| `trades.json` | 交易流水（买入/卖出记录，含账户标记） |
| `基金显示.json` | 已清仓等显示层状态，缺席=默认 |
| `账户.json` | 账户列表（多账户管理） |
| `settings.json` | 用户设置（默认备份目录等） |
| `基金日报导出_*.xlsx` | 你导出的 Excel（默认存 exe 同目录，内含你的数据） |

## 隐私声明
