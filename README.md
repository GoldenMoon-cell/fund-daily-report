Windows / macOS 双平台桌面基金看板：任务导航式工作区、实时行情、持仓盈亏、红黑榜、涨跌柱状图、已清仓灰章、交易记录（买卖/转换/分红）与收益日历、多账户管理、备份恢复、一键导出 Excel。行情取自公募基金接口；**全部持仓与交易数据仅存本地磁盘，不上传**。

## 功能

- 🎨 **四套主题**：深空暗（默认）/晨雾浅色/纸账本/经典，顶栏「设置」切换，即时生效并记住
- 🧭 **任务导航工作区**：左侧常驻「总览 / 账本 / 收益 / 数据与设置」，账户范围全局生效；主页面使用无透明度的轻量滑入，深色主题不闪屏
- 🏠 首页看板：每只基金卡片显示净值/今日涨跌（大字）/累计盈亏/近 60 日迷你走势线，一键刷新；快速添加同时接受 6 位代码和基金名称
- 🧭 参考信号：估值红绿灯（指数基金看跟踪指数 PE/PB 百分位+股息率，主动/商品类如实标注净值分位或无口径）、累计收益止盈参考线提醒、持仓集中度诊断、卡片排序——仅信息展示，不构成投资建议
- 🧮 总持仓市值、今日盈亏与可信统一收益：统一收益 = 未实现收益 + 已实现收益 + 现金分红；流水、份额或本金不完整时明确显示“待补录”，不输出伪精确总数
- 🔥 今日红榜/黑榜 + 涨跌柱状图
- 💼 管理持仓：份额/每份成本录入，自动识别"本金当成本"并换算，支持粘贴导入；「对账」用交易流水逐笔回放校准手填持仓（差异橙底待核对，保存才落盘）
- 📒 交易记录与账本健康：手动记一笔买入/卖出/转换/分红（现金分红、红利再投），支持选中历史流水后编辑；买卖需记录确认份额和金额，期初快照记录份额和剩余本金；“账本健康”按账户核对流水回放与当前持仓的差异
- 📅 收益明细：日历视图 + 月度/年度收益汇总；份额按交易记录/买入日期逐日回溯，从第一笔交易开始记录，休市日与清仓后收益为 0
- 📥 导出 Excel：持仓、交易流水、收益明细、行情快照，勾选后一键导出为一个 Excel（每类数据一个 sheet）
- 📂 多账户：每个账户对应一个平台（支付宝/天天基金/招行等），持仓按账户独立核算，首页可切换“全部账户”或单个账户查看；支持账户间转移持仓
- 🗄 备份与恢复：全部本地数据打包为 zip；恢复前校验并预览，覆盖前自动快照，失败自动回滚；兼容旧版备份
- ℹ 关于本软件：版本信息 / GitHub 链接 / 隐私声明 / 免责声明 / 手动检查更新
- 🚫 已清仓灰章：卖掉的基金盖灰章，不再计入合计与榜单，卡片仅观察；可随时恢复，状态存 `基金显示.json`

## 运行

源码运行（Python 3.10+）：

```
pip install -r requirements.txt
python app.py

```

源码按职责分为 `app.py`（界面与应用编排）、`storage.py`（原子写盘与损坏回退）、`domain.py`（账本与估值纯计算）、`data_sources.py`（外部行情适配）和 `ui_theme.py`（主题令牌与渲染）。

到 Releases 下载对应平台的 zip（Windows 版 / macOS 版），解压到同一文件夹运行，详见 `使用说明.txt`。Windows 双击 exe；macOS 首次需右键 app → 打开（未签名应用的正常拦截）。首次运行，在首页「➕ 快速添加」加入第一只基金，会在程序同目录自动创建 `自定义基金.json`（看板名单）。

> Windows 首次打开若提示“Windows 已保护你的电脑”：这是未签名的正常现象（SmartScreen），非病毒。点「更多信息」→「仍要运行」即可。
> macOS 首次打开若提示“无法验证开发者”：同样是未签名的正常现象，右键 app →「打开」即可。

## 本地文件说明（均不入库）

| 文件 | 用途 |
|---|---|
| `自定义基金.json` | 看板名单 |
| `我的持仓.json` | 持仓账本（份额/成本，按账户分组） |
| `trades.json` | 交易流水（买入/卖出记录，含账户标记） |
| `基金显示.json` | 已清仓等显示层状态，缺席=默认 |
| `账户.json` | 账户列表（多账户管理） |
| `settings.json` | 用户设置（默认备份目录等） |
| `数据版本.json` | 数据格式版本清单，用于备份恢复与迁移校验 |
| `基金日报导出_*.xlsx` | 你导出的 Excel（默认存 exe 同目录，内含你的数据） |

## 隐私声明
