基金日报 v2.2.0 · 使用说明

【这是什么】
一个 Windows / macOS 双平台桌面基金看板：实时行情、持仓盈亏、收益日历、红黑榜、多账户管理、一键备份、一键导出 Excel。
双击 fund-daily-report.exe（Windows）或 fund-daily-report.app（macOS）即可使用，无需安装 Python 或任何环境。
行情取自公开基金接口；持仓、交易记录全部只存在你自己电脑，不上传。

【配置要求】
- Windows 10 / 11，或 macOS 13 及以上
- 无需安装 Python，无需联网配置（首次拉行情需联网）
- 普通电脑即可运行（4GB 内存足够），无显卡要求

【第一次使用】
1. 把本压缩包解压到一个固定文件夹（建议不要放在桌面临时位置，之后别随意移动程序）
2. 启动程序：
   · Windows：双击 fund-daily-report.exe（首次启动约 3~8 秒，属正常现象）
   · macOS：右键 fund-daily-report.app → 打开（首次会被系统拦截，见「常见坑」）
3. 首页点「➕ 快速添加」，输入 6 位基金代码（如 000217）加入看板
4. 点「💼 管理持仓」填写持有份额 / 成本价，盈亏统计才会生效
   • 如果你在多个平台买基金（支付宝、天天基金、招行等），
     可点「⚙ 管理账户」新建账户，然后切换账户分别录入
5. 买卖后可在「📒 交易记录」手动记一笔，用于收益明细回溯
6. 想留存数据：点顶栏「📥 导出」，勾选数据、选保存位置，生成一个 Excel
7. 建议定期点顶栏「🗄 备份」，把所有数据文件打包成 zip 存档（可设置默认目录，下次一键备份）

【本地文件说明】（自动生成在 exe 同目录，可自行备份）
  自定义基金.json      看板里的基金名单
  我的持仓.json        持仓账本（份额 / 成本，按账户分组）
  trades.json          交易流水（买入 / 卖出记录，含账户标记）
  基金显示.json        已清仓等显示状态
  账户.json            账户列表（多账户管理）
  settings.json        用户设置（默认备份目录等）
  走势缓存.json        卡片迷你走势缓存（按日自动更新，删除无妨会重新拉取）
  基金日报导出_*.xlsx  你导出的 Excel（含你的数据，自行保管）
※ 以上文件均不上传，删除后会丢失数据，建议定期备份。

  · 数据源为蛋卷指数估值（非官方接口）：接口挂了或指数未覆盖时自动回退净值分位，不影响使用

【常见坑】
- Windows 第一次打开提示“Windows 已保护你的电脑”：
  点「更多信息」→「仍要运行」即可
- macOS 第一次打开提示“无法打开/无法验证开发者”：
  未签名应用的正常现象，非病毒。右键点 app →「打开」→ 再点「打开」，
  或在「系统设置 → 隐私与安全性」里点「仍要打开」；打开过一次后不再拦
- 杀毒软件报毒：PyInstaller 打包常见误报，把本文件夹加入白名单
- 收益明细和支付宝对不上：按手填份额回溯，可能有 ±几元误差，属正常
- 想升级新版本：直接下载新 zip，把新程序覆盖到本文件夹即可（本地数据文件会保留，旧版持仓自动归入“默认”账户）
